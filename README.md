# Games_Pipeline

**Проект по пайплайну и системе работы с креативами для игр.** Здесь живёт схема производства
игрового креатива — от брифа до сдачи — и её живая страница.

Открыть страницу в интернете: **https://sg19803.github.io/Games_Pipeline/**
Доска задач проекта: **https://github.com/sg19803/Games_Pipeline/issues**
Веха «Пайплайн v1»: **https://github.com/sg19803/Games_Pipeline/milestone/1**

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | страница со схемой пайплайна: 6 блоков, карточки этапов, связи стрелками, поле «Номер креатива», кнопка «Сохранить» (пишет `ai-creative-pipeline.txt` рядом с файлом) |

Страница самодостаточная: ни картинок, ни шрифтов, ни скриптов с других сайтов — весь SVG, CSS и
шрифт Inter (SIL OFL) внутри одного файла.

## Правило для всех ИИ-этапов: только процессор

Все нейросети на рабочей машине считают **на CPU**. 02.11.2026 видеокарта уронила систему в синий
экран (`0x116` VIDEO_TDR_ERROR), поэтому GPU — только по отдельному решению и после подготовки
(TdrDelay, контрольный прогон). Время планируется по замерам: YuE2 — около 17 минут на минуту
звука, ComfyUI SD1.5 512×512/12 шагов — 130 с на картинку.

## Как менять

1. Правится `index.html` (или `PIPELINE.md`) — это источники правды.
2. Публикация: `powershell -ExecutionPolicy Bypass -File C:\SYS_Deepseek\01_SCRIPTS\Publish-GamePage.ps1`
   (сама коммитит с датой, отправляет и печатает адрес страницы).
3. GitHub Pages обновляет копию за 1–2 минуты, страница открывается по адресу выше.

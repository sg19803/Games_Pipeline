# Games_Pipeline

Страница игры — схема пайплайна ИИ-креативов для проекта **Simple Sandbox 3 Pixel Craft**.

Открыть в интернете: **https://sg19803.github.io/Games_Pipeline/**

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | сама страница: заголовок «Пайплайн ИИ-креативов», карточки этапов, связи стрелками, кнопка «Сохранить» (пишет `ai-creative-pipeline.txt` рядом с файлом) |
| `README.md` | это описание |

Страница самодостаточная: ни картинок, ни шрифтов, ни скриптов с других сайтов — весь SVG и CSS внутри одного файла.

## Как менять

1. Правится `index.html` (это единственный источник правды).
2. Изменение публикуется: `git add -A; git commit -m "что изменил"; git push` — или одной командой
   `powershell -ExecutionPolicy Bypass -File C:\SYS_Deepseek\01_SCRIPTS\Publish-GamePage.ps1`
   (она сама коммитит с датой, отправляет и печатает адрес страницы).
3. GitHub Pages обновляет копию за 1–2 минуты, страница открывается по адресу выше.

## Служебное

* `ai-creative-pipeline.html` — снимок страницы до подключения git, в репозиторий не входит (см. `.gitignore`).
* `ai-creative-pipeline.txt` — файл, который пишет кнопка «Сохранить» на странице (локально, тоже не в репозитории).
